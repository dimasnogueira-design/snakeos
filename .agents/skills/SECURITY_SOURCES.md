# Security Skill Provenance

Original `web-security-review`, `api-security-review`, `code-review-security`, `secrets-scan`, `sca-audit`, their companion `plays`, and `templates/finding.md` were copied from https://github.com/OWASP/secure-agent-playbook on 2026-10-16 (license CC BY 4.0). They retain their original references and content; their play and template files were placed into each skill directory so the guidance is usable when installed as project-scoped skills.

Some upstream references to supporting data or third-party tooling require additional online access; never claim those materials/tools were loaded or executed unless verified. `venom-pentest` and `venom-delivery-gate` are VENOM-specific orchestration instructions, not official OWASP audits or independent certifications. Credits: OWASP Secure Agent Playbook contributors, https://github.com/OWASP/secure-agent-playbook/blob/main/LICENSE.md .

Trail of Bits is recommended for optional security expertise (https://github.com/trailofbits/skills); its proprietary skill workflows were not copied into this package.

No active scans run automatically. Testing online targets requires explicit authorization and scope.
